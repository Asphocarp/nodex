# Triage labels

The engineering skills use five canonical triage roles. Nodex uses the same strings in GitHub Issues.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The issue is waiting for reporter information. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified and can be implemented without additional human context. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation or judgment. |
| `wontfix` | `wontfix` | The issue will not be actioned. |

When a skill names a triage role, apply the corresponding GitHub label from this table.
